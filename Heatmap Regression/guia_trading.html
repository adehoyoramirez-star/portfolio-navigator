1. Resumen del Sistema

El sistema combina dos motores independientes: Python para seleccion (QUE comprar, Q5) y Pine Script para timing (CUANDO comprar).

MotorQue haceOutput
Python v5.1Selecciona Q5 basado en fundamentales+tecnicos. IC=+0.043predictions.csv, portfolio_q5.csv
Pine v10.4 HybridAnaliza timing: RSI, BB, regimen, MTF, R:RTabla en TradingView
Clave: El Pine ahora acepta el score Python como input. Cuando ambos coinciden, CONFLUENCIA=SI.

2. Paso 1: Ejecutar Modelo Python

Cada lunes:

cd "Heatmap Regression"
python -X utf8 OLYMPUS_HEATMAP_REGRESSION_v5.py --mode swing

Outputs: predictions.csv (scores Q5/Q1), portfolio_q5.csv (pesos HRP), ibkr_orders.csv (ordenes IBKR).

Luego: python olympus_screener.py para cruzar Q5 con senales tecnicas.

3. Paso 2: Interpretar Pine Script Hybrid

Abrir ticker Q5 en TradingView -> aplicar "Olympus Tactical v10.4 Hybrid".

Inputs a configurar: Olympus Score (score del modelo), Olympus Q (5), Override Q5 (ON).

Filas clave de la tabla:

FilaVerdeRojo
HYBRID SCORE>=70 - BUENA OPORTUNIDAD<50
CONFLUENCIASI - ambos sistemas alineadosNO
OPPORTUNITY>=70<50
R:R>=1.5<1.5
VEREDICTOLISTOMotivo del bloqueo
Regla de oro: Solo operar cuando HYBRID >= 70 y CONFLUENCIA = SI.

4. Paso 3: Reglas de Entrada

7 condiciones: Q5 (score>=70), HYBRID>=70, CONFLUENCIA=SI, senial activa, R:R>=1.5, Entry Zone CONFIRMED, VEREDICTO=LISTO.

5. Paso 4: Reglas de Salida

TipoCondicionAccion
TP1Entry + risk*2Vender 60%, SL a breakeven
TP2Entry + risk*3.2Vender 40%
Stop LossEntry - atr14*2Vender todo
ExhaustionVolumen cae, RSI>75Vender todo
Time Stop10 velas sin TP1Vender todo

6. Gestion de Riesgo

Reglas: 1% riesgo por trade, 3% diario, 5% semanal. Max drawdown -10%. Sin apalancamiento. Max 3 posiciones mismo sector.
No operar cuando: VIX>35, IC<0, 2 perdidas consecutivas, viernes tarde, semana FED.

7. Ejemplo: DELL

Paso 1: Modelo Python -> DELL Q5 score 100.
Paso 2: TradingView -> Inputs Score=100, Q=5, Override=ON.
Paso 3: Tabla: BLOOD activo (RSI2=6.4), HYBRID=82, CONFLUENCIA=SI, VEREDICTO=LISTO.
Paso 4: Con 10.000EUR: 3 acciones DELL a 422EUR. SL=392EUR. TP1=482EUR. TP2=518EUR. R:R=2.5.
